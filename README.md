# Bili Focus

[English](#en) | [简体中文](#zh-cn)

<a id="en"></a>

## English

Bili Focus is an unofficial Bilibili desktop and Android client for watching with a more intentional, personal feed.

Download the latest Android and Windows builds from the [Releases page](https://github.com/IceCubeGG/Bili_focus/releases/latest).

### Main features

- **Focused Browse** — Create recommendation presets that allow only selected tags and uploaders. Choose whether tags and uploaders use AND or OR matching, or return to the unfiltered feed at any time.
- **Subscriptions and groups** — See uploads from followed creators, open one creator's complete available video library, or make local creator groups like social-media lists.
- **Search** — Search videos by keyword or an exact BV code, then load more results when available.
- **Video page** — Watch videos with parts/episodes, title, uploader, tags, description, comments, Danmu controls, playback speed, fullscreen, and available quality choices. Compatible quality is the safe default.
- **Downloads and folders** — Download the current video part or its cover. Add multiple save folders, select the destination for new downloads, browse saved media, and open files with your device's viewer.
- **Account and appearance** — Sign in with QR code or through Bilibili's official password/SMS page. Use English or Simplified Chinese, and choose system, light, or dark appearance.

### How to use Bili Focus

1. Download the release for Windows or Android and install it. On Android, install an update over the existing app to keep your local settings.
2. Open **Options** and sign in if you want subscriptions, comments, Danmu sending, or account-only video access. Choose **QR sign-in**, or open Bilibili's official sign-in page for password/SMS sign-in.
3. Open **Browse**. Use **Feed settings** to create a preset, add tags or uploader IDs, save it, then select it to focus recommendations. Choose **All recommendations** to remove filtering.
4. Open **Subscribe** to see recent uploads from accounts you follow. Use **Show subscriptions** to pick one uploader, or create/select a group to combine creators.
5. Use the search button in the top bar for a keyword or BV code. Select a result to open its video page.
6. On a video page, choose a part, adjust playback controls or quality, turn Danmu on/off, and use **Download** or **Download cover** when you want to save media.
7. Return to **Options → Save folder & downloads** to manage destinations, view download progress, and browse saved files.

Some videos, quality levels, comments, Danmu, and download options depend on the upload, your account permissions, network, and Bilibili's current availability.

## 简体中文

Bili Focus 是一个非官方的哔哩哔哩 Windows 和 Android 客户端，帮助你按自己的兴趣更专注地浏览和观看内容。

请在 [Releases 页面](https://github.com/IceCubeGG/Bili_focus/releases/latest) 下载最新版 Android 或 Windows 客户端。

### 主要功能

- **专注浏览** — 创建推荐预设，只显示指定标签和 UP 主的视频。可选择标签与 UP 主使用“同时满足”或“满足其一”的匹配方式，也可随时切回未筛选的推荐。
- **关注与分组** — 查看已关注 UP 主的投稿，打开单个 UP 主的完整可用视频库，或像社交媒体列表一样建立本地 UP 主分组。
- **搜索** — 可使用关键词或精确 BV 号搜索视频，并在有更多内容时继续加载。
- **视频页** — 提供分 P/选集、标题、UP 主、标签、简介、评论、弹幕控制、倍速、全屏和可用清晰度选择。默认使用更稳定的“兼容”清晰度。
- **下载与保存文件夹** — 下载当前分 P 或封面；可添加多个保存文件夹，为新下载选择目标位置，浏览已保存的媒体，并用设备上的播放器或图片查看器打开文件。
- **账号与外观** — 支持扫码登录，或通过哔哩哔哩官方密码/短信页面登录；可切换英文、简体中文，以及跟随系统、浅色或深色外观。

### 使用方法

1. 下载 Windows 或 Android 版本并安装。Android 更新时可直接覆盖安装，以保留本地设置。
2. 打开 **选项**，如需查看关注、发表评论、发送弹幕或访问仅限登录账号的视频，请先登录。可选择**扫码登录**，或打开哔哩哔哩官方登录页使用密码/短信登录。
3. 打开 **浏览**。进入**推荐设置**创建预设，添加标签或 UP 主 UID，保存后选择该预设即可筛选推荐。选择**全部推荐**可取消筛选。
4. 打开 **关注**，查看已关注账号的最新投稿。使用**显示关注列表**选择单个 UP 主，或创建/选择分组来合并多个 UP 主的内容。
5. 点击顶部搜索按钮，输入关键词或 BV 号；选择结果即可打开视频页。
6. 在视频页中选择分 P，调整播放控制或清晰度，开启/关闭弹幕；需要保存时使用**下载**或**下载封面**。
7. 前往 **选项 → 保存文件夹与下载**，管理保存位置、查看下载进度，并浏览已保存的文件。

部分视频、清晰度、评论、弹幕和下载功能会受到投稿本身、账号权限、网络以及哔哩哔哩当前服务状态的影响。
