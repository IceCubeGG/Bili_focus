# Bili Focus 0.4.0 — Search videos

- Search videos by keyword or exact BV code from the top bar on Windows and Android.
- Load more keyword results, open videos in the existing player, and return to preserved search results.
- Search remains separate from strict Browse presets, with English and Simplified Chinese support.
- English video terminology now uses tag/tags. Existing saved presets are preserved.
- Keeps compatible playback, optional quality selection, subscriptions/groups, Danmu, comments, downloads and save-folder management.

Downloads: Android debug APK and Windows x64 portable ZIP, plus SHA256SUMS.txt. Android version code 4 uses the existing development signing certificate; install as an update without uninstalling to preserve app data. Windows remains unsigned: extract the ZIP and run Bili Focus.exe.

Account credentials and guest cookies remain native. Platform restrictions/verification may limit search. Only save content you have permission to keep. No real phone or emulator was accessed during this update; Android search and playback still require device verification.
